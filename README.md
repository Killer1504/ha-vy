## ✨ Features

| Feature | Description |
|---|---|
| 🌺 **Hero Section** | Animated entrance with floating petal particles |
| 👩‍⚕️ **Tribute** | A heartfelt tribute to a future pediatrician |
| 🎯 **8 Reasons** | Interactive cards — 8 reasons for Women's Day |
| 🐱🐶 **Cute Gallery** | AI-generated adorable animal images |
| 💌 **Wishes Card** | A final love letter with floating hearts |
| 🎵 **Music Player** | Background music with animated toggle |
| 🌸 **Falling Petals** | Continuous cherry blossom particle effect |
| 📱 **Responsive** | Beautiful on mobile, tablet, and desktop |

## 🛠️ Tech Stack

- **HTML5** — Semantic structure
- **CSS3** — Animations, gradients, glassmorphism
- **Vanilla JavaScript** — Intersection Observer, particle system
- **Google Fonts** — Playfair Display, Inter, Dancing Script

## 🎨 Design

The design follows a **Warm Bloom** palette — soft pinks, warm corals, and elegant ivory — crafted to feel romantic and personal.

| Element | Style |
|---|---|
| **Typography** | Playfair Display (headings), Dancing Script (accents), Inter (body) |
| **Colors** | Soft rose `#E8A0BF` · Deep coral `#C75B7A` · Warm ivory `#FFF5EE` |
| **Effects** | Glassmorphism cards, floating petals, scroll-reveal animations |

## 💻 Run Locally

No build step required — just open in a browser:

```bash
# Clone the repo
git clone https://github.com/Killer1504/ha-vy.git

# Open in browser
start index.html    # Windows
open index.html     # macOS
xdg-open index.html # Linux
```

Or use Live Server in VS Code for hot reload.
